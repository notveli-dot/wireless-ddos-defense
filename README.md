# wireless-ddos-defense
A python-based DDOS attack detection and mitigation system with machine learning Integration
#features
-Real-time packet capture and analysis
-Threshold-based attack detection(SYN, UDP, ICMP, HTTP floods)
-ML ensemble: Random Forest, XGBoost, SVM, Isolation Forest
-Rate limiting and IP blacklisting
-Automatic SYN cookie protection
